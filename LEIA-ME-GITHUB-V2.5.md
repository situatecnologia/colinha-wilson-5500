# Santinho Virtual Wilson Martins 5500 — V2.5

## Ajuste principal para smartphone

A ordem da interface em telas de celular agora é:

1. Campos de preenchimento dos candidatos
2. Prévia do Santinho Virtual
3. Botões de ação:
   - Compartilhar Santinho
   - Salvar PNG
   - Copiar lista
   - Imprimir
   - Limpar tudo

No desktop, a prévia permanece à esquerda e os campos/botões à direita.

## Upload manual no GitHub

Envie o CONTEÚDO desta pasta para a raiz do repositório:

- index.html
- cadastro-candidatos.js
- manifest.webmanifest
- service-worker.js
- .nojekyll
- assets/candidatos/

O arquivo index.html deve ficar diretamente na raiz do repositório.
