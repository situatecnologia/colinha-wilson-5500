# Colinha Wilson Martins 5500 — V2.8.1

Ajustes:
- botão principal renomeado para `Compartilhar Colinha`;
- botão `Imprimir` refeito para maior compatibilidade com celular e desktop;
- a impressão agora abre uma página exclusiva com a imagem da colinha;
- tenta chamar o diálogo de impressão automaticamente;
- se o navegador bloquear a impressão automática, a página exibe um botão `Imprimir` para o usuário tocar manualmente;
- se o navegador bloquear a abertura da nova janela, o aplicativo orienta usar `Salvar PNG`.

As demais regras da V2.8.0 foram mantidas.
